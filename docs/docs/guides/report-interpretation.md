# Understanding SpineReport Reports

This guide explains how to interpret the radiological reports generated by SpineReport.

## Report Sections

### 1. Cover Page / Patient Information

The first page contains:
- **Patient Demographics**: Name, Age, Sex, MRI Date
- **Clinical Indication**: Reason for imaging
- **Examination Details**: Imaging protocol, sequence information
- **Report Metadata**: Generation date and version

### 2. Descriptive Findings

This section describes:
- **Spinal Alignment**: Overall alignment and curvature
- **Vertebral Bodies**: Height, signal intensity, degenerative changes
- **Intervertebral Discs**: Hydration, bulging, herniation
- **Spinal Canal**: Diameter, stenosis assessment
- **Neural Foramina**: Foraminal patency, nerve compression

### 3. Morphometric Measurements

Detailed measurements of spinal structures:

**Spinal Canal Measurements:**
- Sagittal canal diameter (mm)
- Cross-sectional area (mm²)

**Vertebral Measurements:**
- Vertebral body height (mm)
- Vertebral body width (mm)
- Endplate area (mm²)

**Disc Measurements:**
- Disc height (mm)
- Disc area (mm²)
- Disc bulging distance (mm)

**Foraminal Measurements:**
- Foraminal width (mm)
- Foraminal height (mm)
- Nerve root compression percentage (%)

### 4. Comparative Analysis Graphs

Graphs comparing the patient's measurements to a control group:

#### Violin Plots
- **Gray violins**: Distribution of measurements in control group
- **Red line**: Patient's measurement value
- **Height of violin**: Density of control group values

**Interpretation:**
- If patient value is at the top/bottom → extreme measurement
- If patient value is at the middle → normal measurement
- If patient value is within dense part → typical for population

#### Box Plots
- **Box**: Middle 50% of control group values
- **Line inside box**: Median (50th percentile)
- **Whiskers**: Range of typical values
- **Red dot**: Patient's value

**Interpretation:**
- Within box → normal range
- Outside whiskers → abnormal (very high or very low)

### 5. Statistical Summary

Percentile rankings showing where patient falls in control population:

| Measurement | Patient Value | Percentile | Status |
|---|---|---|---|
| Canal Diameter | 12.5 mm | 85th | High-normal |
| Vertebrae Height | 24.2 mm | 45th | Normal |
| Disc Height | 8.1 mm | 25th | Low |

**Percentile Ranges:**
- **>95th or <5th percentile**: Abnormal
- **80-95th or 5-20th**: High/Low normal
- **20-80th percentile**: Normal range

### 6. Clinical Summary

Automated interpretation of findings including:
- Severity assessment
- Relevant comparisons to control population
- Clinical significance of abnormal findings

## Understanding Measurements

### Spinal Canal Diameter
**Normal Range:** 12-20 mm (varies by level)
- **>15 mm**: Normal
- **12-15 mm**: Borderline stenosis
- **<12 mm**: Severe stenosis

### Vertebral Body Height
**Normal Range:** 23-27 mm (cervical) to 20-25 mm (lumbar)
- Decreased height suggests compression fracture
- Compare between levels for asymmetry

### Disc Height
**Normal Range:** 7-10 mm (varies by spine region)
- Decreased height suggests degeneration
- <4 mm indicates significant degeneration

### Foraminal Width
**Normal Range:** 10-15 mm
- <8 mm may indicate nerve compression
- Consider clinical symptoms

## Interpreting Comparisons

### What the Graphs Show

**Patient vs. Control Population:**
- Control group (violin/box) represents healthy reference population
- Patient value compared against this distribution
- Helps identify if findings are abnormal for age/demographics

### Clinical Significance

**Finding is significant if:**
1. Patient value is in >95th or <5th percentile
2. Multiple abnormal measurements
3. Clinical correlation with symptoms
4. Progressive changes if prior studies available

### Not All Outliers are Pathological

- Measurements are from automatic segmentation
- Some variation is expected
- Clinical context is crucial
- Consider patient symptoms and history

## Limitations

- **Automated Analysis**: Results should be reviewed by radiologist
- **Segmentation Errors**: Boundary errors affect measurements
- **Image Quality**: Poor image quality affects accuracy
- **Individual Variation**: Wide range of normal exists
- **Control Group Dependent**: Results depend on control population used

## Confidence in Results

High confidence when:
✓ Clear image quality
✓ Good segmentation boundaries
✓ Measurements reasonable for clinical context
✓ Multiple measurements show consistent pattern

Lower confidence when:
✗ Poor image quality
✗ Motion artifacts present
✗ Unclear segmentation boundaries
✗ Single outlier measurement (others normal)

## Recommendations

1. **Always Review**: Have radiologist review automated results
2. **Cross-Reference**: Compare with clinical history and symptoms
3. **Follow-up**: Request prior imaging if abnormalities found
4. **Clinical Correlation**: Important abnormalities warrant clinical review
5. **Documentation**: Document reviewer's interpretation
